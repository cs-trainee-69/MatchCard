# Result screen design

## Layout correction: unobstructed stitching

The active frame is now drawn with CSS: a cream surface, pink rim and a separate dashed inset border. The original generated panel assets below are retained as design history, but are no longer displayed or preloaded. This removes the baked-in paw and stars that covered parts of the stitching and prevents distortion when content height changes.

The celebration cat perches on the outer top-right rim, entirely above the inset stitching. Text and actions use at least 34px of inset from the panel edge; the ranking mascot is reduced to 34px inside the secondary button. The device-only note and eligibility copy use larger type. Stat labels reserve equal height even when High Score wraps. The overlay scrolls on short screens.

Regression verification measures that the cat sits on the right half with its paws no more than 8px below the outer top edge and that the replay button stays at least 30px inside both sides, in addition to checking ranking and replay across viewport sizes.

## Reference and layout

The approved concept uses one cream panel with a glossy coral pink rim, peach stitching, an orange cat, a gold paw and stars. The successful-submission badge (บันทึกคะแนนแล้ว) is omitted.

Content order: Game Result, Time's up!, optional New High Score, Score / High Score / Round, actual submission eligibility or recovery status, เล่นอีกครั้ง, ดูอันดับออนไลน์, and the device-only High Score note. The same cream and gold ranking button appears before play.

The layout follows content height rather than a square aspect ratio. On short screens the result overlay scrolls, keeping all actions reachable. Scores, copy, buttons and the trophy icon are rendered by the application. The illustration contains no baked-in text or interactive controls.

Rebuild delivery variants with `npm run assets:optimize`.

Match the reference frame material, colors and illustration exactly. Portrait panel ratio 0.72 width to height, front-on, no perspective, panel fills canvas with a small 3% transparent outer margin. Fully transparent background outside the panel; opaque cream inside. No cat mascot, no title, no text, no numbers, no buttons, no stat tiles, no status pills, no background game cards. Entire center is clean empty cream reserved for live HTML. Keep gold decorations constrained to bottom 12% and outer corners so they cannot overlap live content. This is a reusable empty panel asset, NOT a complete screen. Crisp polished casual cat game illustration, soft restrained shadows.

## Verification

Use local Game Center fixtures for result acceptance, eligibility, failed-result retry, rankings, keyboard focus restoration and replay. Production rounds are not created during UI verification.

Validated on 2026-10-15: production build passed, 70 unit tests passed, and 49 browser tests passed with four workers. Result screenshots were visually checked at 320 × 480, 390 × 844 and 1280 × 720. The browser suite includes result-to-ranking focus restoration, replay, failed-submission retry and the absence of successful-submission copy.
